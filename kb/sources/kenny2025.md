# Agreement in Voice Gender Perception Between Cisgender and Transgender/Gender-Diverse Listeners

## What it says
- Design: 40 voice recordings "with user comments" were extracted from r/transvoice, the Reddit forum where TGD people post and discuss voice. Comments by TGD users were coded into four categories — masculine, feminine, gender-neutral, undecided — and 26 cisgender listeners rated the same recordings on the same four categories (abstract, "Methods").
- Weighted percentage scores per category became continuous variables for Spearman correlation; within-group reliability used Krippendorff's alpha with bootstrapped 95% CIs.
- Strong agreement between the two listener groups on masculine (r(s) = 0.72, P < 0.001) and feminine (r(s) = 0.75, P < 0.001) voices.
- "Agreement was weaker and non-significant for weighted gender-neutral ratings (r(s) = 0.28, P = 0.77)." No correlation could be run for "undecided", because "no TGD listeners selected this option".
- Within-group reliability: "fair for cisgender listeners (alpha = 0.40 ... 78% consensus) and moderate for TGD listeners (alpha = 0.54 ... 84% consensus)".

## Bearing on voice training
- Measures the exact feedback loop community practice runs on: peer listeners sampled from the same forum that supplies the recordings. The result is reassuring for the masculine/feminine ends and uninformative in the middle — which is where androgynous and non-binary targets live [[nonbinary-voice]] [[gender-perception]].
- TGD listeners agreed with each other more than cisgender listeners did, which the authors attribute to shared experience; still only "moderate" reliability, so peer ratings are noisy evidence even inside the community [[english-community]] [[voice-impressions]].

## Notes
- n = 40 recordings (self-selected posts), TGD ratings taken from public comments rather than a controlled listener task, 26 cisgender listeners. Trinity College Dublin. Sampling from a public forum means the recordings are not a clinical or a representative sample.
- Claims taken from the PubMed abstract.
