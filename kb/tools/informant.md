# InFormant

Open-source desktop/mobile "real-time pitch and formant tracking software" (README). The README of the default branch says that branch is unmaintained and development continues on the `with-qt` branch; builds are described for Linux, Windows, macOS, Android and Emscripten.

## What it offers
- Live pitch and formant tracks while speaking, which is what voice-training users use it for.
